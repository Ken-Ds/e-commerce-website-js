# Project Name

INGS InGenius Website

## Description

Featuring booths where students can display and sell their unique creations, fostering community engagement and supporting local artisans. This website serves as a platform to highlight and support student innovation.

---
## Installation and Setup

### Prerequisites

- **Node.js**: Ensure Node.js is installed on your system.
- **WAMP**: Install WAMP for local server and database management, ensuring it is running.
- **SQL Database**: Import the required SQL database for the project.

### Seting up

1. **Navigate to the Project Directory through cmd**
  
   cd C:\wamp64\www\ings-website\customer
   
2. **Run the Server**
   
  C:\wamp64\www\ings-website\customer:node index.js
   
3. **Access the Website**
   Open your preferred browser and navigate to:
   
   localhost/ing-website/shared/pages/login.php
   
   You will be directed to the login page of the website.

---
### Additional Configuration

- Configure any necessary environment variables.
- Ensure database connections are properly set up.
